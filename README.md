## Hi, I'm Apurva 👋

**AI Product Designer & Builder** from Anand, Gujarat, India.
I design and build AI-powered tools that take the busywork out of running a business.

I start every project by understanding the people who'll use it and sketching the flow in Figma. Then I build the real thing. These days that means CRMs and internal tools where AI agents and automations handle the repetitive work, so nobody has to copy data between spreadsheets or re-send the same email by hand.

- 🔭 **Working:** Career Advisor at StarTech Career LLC, where I designed and built the team's AI CRM. 5 advisors use it every day.
- 🎓 **Studying:** B.Tech in Information Technology at MBIT, Anand (2024 – 2028)
- 🌱 **Learning:** core AI engineering
- 💬 **Ask me about:** AI agents, workflow automation, CRMs and UX design
- 🟢 **Open to new projects:** see my work at **[apurva-patel.vercel.app](https://apurva-patel.vercel.app)**

### 🛠️ Things I've built

- **[AI-powered CRM](https://apurva-patel.vercel.app/work/ai-crm):** a lead-management CRM for my team of career advisors. It replaced manual Google Sheets entry and hand-sent emails.
- **[DayFlow](https://github.com/apurvapatel27/DayFlow):** an HR system built with team TechFlow at the Odoo × GCET hackathon, with attendance, leave approvals and salary breakdowns. I designed and developed the app. ([live demo](https://day-flow-tawny.vercel.app))
- **[CyberPulse-Sniffer](https://github.com/apurvapatel27/CyberPulse-Sniffer):** an intrusion-detection prototype. A FastAPI service scores network traffic with XGBoost and Random Forest models, and a React dashboard shows the alerts.
- **[Employee Payroll System](https://github.com/apurvapatel27/Employee-Payroll-System):** a Java web app for payroll records, built with Servlets, JSP and MySQL.
- **[This portfolio](https://github.com/apurvapatel27/personal-portfolio):** a notebook-style site built with Next.js, with a scroll-through story at [/explained](https://apurva-patel.vercel.app/explained).
